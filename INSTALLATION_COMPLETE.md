## 🐛 Troubleshooting

### If something's not working:

**Clear cache and restart:**
```bash
rm -rf .next
npm run dev
```

**Reinstall if needed:**
```bash
npm install
npm run dev
```

**Different port:**
```bash
PORT=3001 npm run dev
# Then: http://localhost:3001/fintrack
```
