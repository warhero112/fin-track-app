# Rentora - Japan Real Estate for Foreigners

A modern, comprehensive real estate website designed specifically for foreigners looking to find homes in Japan. Built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Images**: Next.js Image Optimization

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Deployment

The site is configured for deployment on Vercel, Netlify, or any other Next.js hosting platform.
